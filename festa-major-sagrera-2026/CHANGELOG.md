# Changelog

All notable changes to this guide are documented here.

## [Unreleased]

## [1.1.0] — 2026-11-19

### Added
- Citymapper in Directions for every place, with map coordinates from
  Barcelona's open data and the Catalan mapping institute (ICGC). Add to
  calendar entries now carry the coordinates too.

## [1.0.0] — 2026-11-12

### Added
- First version: every day from November 12 to 22, with times, places,
  Directions and Add to calendar for each event, in Catalan, Castilian and
  English.
- Sign up and More information links to the official pages the program names.
- Where the program contradicts itself, the event follows the detailed listing
  and notes the other version.
